HTML5 Games Explained: How They Run in Your Browser

Years ago, most browser games needed Adobe Flash Player. Flash was officially discontinued at the end of 2020, and modern browser games now run on open web technologies instead. Here is how that works.

The three building blocks

  • HTML defines the page and the area where the game appears.
  • JavaScript contains the game logic: movement, scoring, collisions and rules.
  • The Canvas and WebGL draw graphics. Canvas is great for 2D games, while WebGL uses your graphics hardware for 3D scenes.

Why no download is needed

The game files are loaded into your browser like any web page. Your browser runs the code inside a sandbox, which means the game cannot freely access your files or other programs. This is one reason web games are considered convenient and relatively safe compared with installing unknown software.

Sound and controls

The Web Audio API plays sound effects and music, while keyboard, mouse, touch and even gamepad events provide controls. Many games adapt automatically to phones and tablets.

Saving progress

Most simple games save progress in your browser's local storage. That data stays on your device, so clearing your browser data can erase saved games. If a game matters to you, avoid clearing site data.

Performance tips

  • Keep your browser up to date.
  • Close heavy tabs while playing.
  • If a game stutters, lower the window size or try another browser.

Because HTML5 games run almost anywhere, they are a good fit for school computers, laptops and phones alike.
